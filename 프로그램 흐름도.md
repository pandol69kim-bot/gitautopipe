## CLI 실행 흐름

```mermaid
flowchart TB
  Start["node dist/cli/index.js command"] --> Dotenv["load .env"]
  Dotenv --> Parse["parse command"]
  Parse --> PreAction["preAction hook"]
  PreAction --> Config["load or create config"]
  PreAction --> Logger["set log level"]
  Config --> Secured["executeCliCommand"]
  Logger --> Secured

  Secured --> Resource["build resource"]
  Secured --> Secrets["get required secrets"]
  Resource --> Security["executeSecuredCommand"]
  Secrets --> Security

  Security --> Access["check access"]
  Access --> RateLimit["check rate limit"]
  RateLimit --> SecretCheck["check secrets"]
  SecretCheck --> Handler["run command handler"]
  Handler --> Format["format result"]
  Format --> AuditSuccess["audit success"]
  AuditSuccess --> Output["print result"]

  Access -. failure .-> AuditFail["audit failure"]
  RateLimit -. failure .-> AuditFail
  SecretCheck -. failure .-> AuditFail
  Handler -. failure .-> AuditFail
  AuditFail --> Error["exit with error"]
```

## 해석 주의

CLI와 워크플로우는 현재 로컬 실행 흐름 기준으로 정상 동작합니다. 다만 일부 워크플로우 step은 실제 외부 API 호출이 아니라 완료 메시지를 반환하는 형태입니다. 실제 GitHub, Claude, Notion, Vercel 라이브 연동 검증은 integration 모듈별 API 스모크 테스트를 별도로 실행해야 합니다.

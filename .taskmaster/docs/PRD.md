# 셀피시 클럽 AI 에이전트 협업 시스템 — 핵심 정리

## 1. 핵심 개념

| 항목 | 내용 |
|------|------|
| 조직 | 셀피시 클럽 (대표: 젬마/신주해) |
| 목표 | 개인 AI 활용 → **팀 단위 AX(AI 전환)** |
| 핵심 도구 | Obsidian + Claude Code + GitHub |

---

## 2. 지식 관리 구조 (Obsidian 폴더)

| 폴더 | 역할 |
|------|------|
| `Mission` | 주차별 개인 과제 및 결과물 (마크다운) |
| `Meetings` | 위클리 회의록 (노션 MCP 동기화) |
| `Skill/Insight` | AI 툴·플러그인 정보 → 웹사이트 자동 게시 |
| `Sharing` | 공유회 초안 및 사전 질문 (Claude Code 협업) |
| `Analysis` | Claude Code가 생성한 분석 보고서 |
| `LinkedIn` | 개인 과제 기반 SNS 콘텐츠 초안 |

---

## 3. 자동화 워크플로우

```
멤버 기록 (Obsidian)
    → GitHub Push (클라우드 동기화)
        → Claude Code 분석
            ├── Analysis 폴더: 참여 이력·키워드·주차별 요약 보고서
            ├── LinkedIn: SNS 게시글 초안 자동 생성
            └── Vercel: 웹사이트 자동 배포 (Publit 스킬)
```

---

## 4. 인간 vs AI 역할 분담

| 주체 | 역할 |
|------|------|
| **AI** | 데이터 요약, 분석 보고서 생성, 웹 배포, SNS 초안 (반복 실행 업무) |
| **인간** | 전략 선택, 고급 의사결정, 팀 방향성 설정 (판단·결정) |

---

## 5. 주요 성과

- 회의록·기록 → **분석 보고서** 자동 생성
- 과제 내용 → **링크드인 포스팅** 자동 초안
- 폴더 업데이트 → **웹사이트 실시간 배포**
- 기록이 단순 아카이빙을 넘어 **비즈니스 자산·마케팅 수단**으로 전환

---

## 6. 향후 계획

- **워크플로우 투명 공개**: 과정(삽질 포함) 전체 오픈
- **AA 스타터 키트**: Claude Code 기반 운영 시스템 템플릿 오픈소스 공유
- **커뮤니티 확장**: 비개발자·마케터 대상 AI 비즈니스 OS 도입 지원

---

## 핵심 메시지

> "회의록과 기록이 아카이빙 이상의 역할을 하게 할 수 없을까?"
>
> Obsidian(저장소) + Claude Code(실행 에이전트) = 기록 → 보고서·콘텐츠·포트폴리오 **자동 변환**

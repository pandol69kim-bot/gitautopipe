## 현재 주의사항

- 현재 작업트리에 미커밋 변경이 남아 있음
  - `ai-job-command.txt`
  - `vault/analysis/2026-19_weekly_report.md`
- `onGitHubSync`는 현재 상태에서 실행하면 위 변경까지 함께 커밋/푸시될 수 있음
- `status` 명령 출력에는 `onGitHubSync`, `onNotionSync`가 포함되지 않아, 등록 상태 조회 UX는 실제 정의와 불일치함

## 실제 통신 정리

- `onNotionSync`: 실제 Notion API 및 Obsidian 동기화 경로 통신 확인
- `weeklyDigest`: 실제 GitHub push 및 webhook POST 통신 확인
- `onMissionUpdate`: 현재 로그 스텝만 있어 실제 외부 통신 없음
- `onMeetingSync`: 현재 실행 결과 기준 외부 통신 없음, 로컬 보고서 생성만 확인
- `onSkillUpdate`: 현재 로그 스텝만 있어 실제 외부 통신 없음
- `onGitHubSync`: 미실행으로 실제 통신 미확인

## 결론

- 현재 기준에서 가장 신뢰도 높게 정상 동작이 확인된 워크플로우는 `onNotionSync`와 `weeklyDigest`
- `onMeetingSync`는 보고서 생성까지는 정상
- `onMissionUpdate`, `onSkillUpdate`는 오케스트레이션 성공만 확인됨
- `onGitHubSync`는 실제 동작 확인 전 작업트리 정리가 먼저 필요함

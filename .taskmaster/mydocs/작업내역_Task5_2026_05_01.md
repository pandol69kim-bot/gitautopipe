## 구현 상세

### 1. 타입 정의 (`src/types/report.ts`)

```typescript
type ReportType = 'weekly' | 'member' | 'team';

type SectionType =
  | 'highlights' | 'keywords' | 'member-contributions'
  | 'trends' | 'team-overview' | 'summary';

interface ReportSection {
  type: SectionType;
  title: string;
  content: string;
}

interface ReportMetadata {
  weekNumber?: number;
  memberId?: string;
  totalDocuments: number;
  participationRate?: number;
  topKeywords: string[];
  tags: string[];
}

interface Report {
  title: string;
  type: ReportType;
  generatedAt: Date;
  sections: ReportSection[];
  metadata: ReportMetadata;
  markdownOutput: string;
}
```

### 2. ReportGenerator 클래스 (`src/core/report-generator.ts`)

#### 주요 메서드

| 메서드 | 설명 |
|--------|------|
| `generateWeeklyReport(weeklyData)` | 주차별 보고서 생성 (highlights, keywords, trends, summary 섹션) |
| `generateMemberReport(memberId, contributions)` | 멤버별 기여 보고서 생성 |
| `generateTeamOverview(history)` | 팀 전체 트렌드 개요 보고서 생성 |
| `saveReport(report, outputPath)` | YAML frontmatter + 마크다운 파일 저장 |
| `generateFileName(type, weekNumber?, memberId?)` | 파일명 규칙 생성 |

#### 파일명 규칙

```
weekly  → YYYY-WW_weekly_report.md      (예: 2026-03_weekly_report.md)
member  → YYYY_member_report_{id}.md   (예: 2026_member_report_alice.md)
team    → YYYY_team_overview.md
```

#### YAML Frontmatter 예시 (saveReport 출력)

```yaml
---
title: "Week03 활동 보고서"
date: 2026-05-01
tags:
  - weekly
  - week03
  - selfishy
keywords:
  - React
  - TypeScript
  - Hooks
week: 3
---
```

#### 설계 포인트

- `ClaudeAnalyzer` 전체가 아닌 `Pick<ClaudeAnalyzer, 'generateSummary' | 'extractKeywords' | 'identifyTrends'>` 타입으로 최소 의존성 주입
- `generateWeeklyReport`에서 summary, keywords, trends를 `Promise.all`로 병렬 호출
- `buildFileContent`는 순수 함수 — frontmatter와 markdown 본문을 조합

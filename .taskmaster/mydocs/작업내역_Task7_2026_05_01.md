## 구현 상세

### 1. 타입 정의 (`src/types/notion.ts`)

```typescript
type NotionBlockType =
  | 'paragraph' | 'heading_1' | 'heading_2' | 'heading_3'
  | 'bulleted_list_item' | 'numbered_list_item'
  | 'to_do' | 'code' | 'image' | 'divider';

interface NotionPage {
  id: string;
  url: string;
  createdAt: Date;
  lastEditedAt: Date;
  title: string;
  properties: Record<string, unknown>;
  blocks: NotionBlock[];
}

interface SyncMetadata {
  notionPageId: string;
  obsidianPath: string;
  lastSyncedAt: Date;
  notionLastEditedAt: Date;
  obsidianLastEditedAt: Date;
}

type ConflictResolution = 'notion-wins' | 'obsidian-wins' | 'manual';

interface MergeResult {
  resolution: ConflictResolution;
  content: string;
  conflictDetails?: string;
}
```

### 2. NotionMCPConnector 클래스 (`src/integrations/notion.ts`)

#### 주요 메서드

| 메서드 | 설명 |
|--------|------|
| `fetchMeetings(databaseId)` | Notion DB 쿼리 → NotionPage 배열 (블록 포함) |
| `syncToObsidian(page, path)` | Notion 블록 → Obsidian 마크다운 + YAML frontmatter 저장 |
| `syncFromObsidian(file, dbId)` | 마크다운 파싱 → Notion 블록 역변환 + pages.create |
| `resolveConflicts(local, remote)` | 최신 수정 시간 기준 충돌 자동 해결 |
| `buildSyncMetadata(page, path)` | 동기화 메타데이터 객체 생성 |
| `blockToMarkdown(block)` _(static)_ | 단일 Notion 블록 → 마크다운 문자열 변환 |

#### 블록 변환 지원 목록 (`blockToMarkdown`)

| Notion 블록 타입 | 마크다운 출력 |
|-----------------|--------------|
| `paragraph` | 일반 텍스트 |
| `heading_1` | `# 제목` |
| `heading_2` | `## 제목` |
| `heading_3` | `### 제목` |
| `bulleted_list_item` | `- 항목` |
| `numbered_list_item` | `1. 항목` |
| `to_do` (미완료) | `- [ ] 할 일` |
| `to_do` (완료) | `- [x] 할 일` |
| `code` | ` ```언어\n코드\n``` ` |
| `divider` | `---` |

#### 충돌 해결 전략

```
Notion 수정 시간 >= Obsidian 수정 시간 → notion-wins (Notion 내용으로 덮어씀)
Obsidian 수정 시간 > Notion 수정 시간   → obsidian-wins (Obsidian 내용 유지)
동일 시간                              → notion-wins (기본값)
```

#### YAML Frontmatter 출력 예시 (syncToObsidian)

```yaml
---
title: 2026-05-01 팀 미팅
notionId: page-001
date: 2026-05-01
---
```

#### 설계 포인트

- `NotionClient` 인터페이스로 `@notionhq/client` 의존성 주입 (테스트 가능성 확보)
- `fetchMeetings`에서 `databases.query` + `blocks.children.list`를 `Promise.all`로 병렬 처리
- `markdownToBlocks`로 마크다운 역변환 지원 (heading / bullet / numbered / to_do / paragraph)
- `gray-matter`로 frontmatter 파싱 (`syncFromObsidian`)

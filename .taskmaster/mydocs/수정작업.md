# 수정 작업 정리

작성일: 2026-05-06

## 목적

- `onMeetingSync` 워크플로우가 실제 Analysis 주간 보고서를 생성하도록 연결한다.
- 분석 공급자를 Claude/OpenAI 공용 구조로 정리하고, 당분간 OpenAI를 기본 운영값으로 맞춘다.
- 운영 문서와 환경 변수 예시도 같은 기본값으로 정렬한다.
- 실환경 smoke test로 Claude/OpenAI 경로를 각각 확인한다.

## 주요 수정 사항

### 1. onMeetingSync 실제 보고서 생성 연결

- `src/workflows/orchestrator.ts`
  - 기존 `report-update` 로그 스텝을 실제 실행 스텝으로 교체했다.
  - `meeting:synced` 이벤트 시 meetings 폴더를 스캔해 같은 주차 문서를 수집한다.
  - `ReportGenerator`를 호출해 `vault/analysis`에 주간 보고서를 저장한다.
  - 실패 시 `Analysis 보고서 업데이트 실패: ...` 형태의 문맥 있는 에러를 남기도록 정리했다.
- `src/workflows/orchestrator.test.ts`
  - `meeting:synced` 이벤트로 실제 보고서 파일이 생성되는 focused test를 추가했다.

### 2. 분석기 추상화 및 OpenAI 지원 추가

- `src/types/analysis.ts`
  - 보고서 생성기가 Claude 구체 타입 대신 공용 `AnalysisEngine` 인터페이스에 의존하도록 분리했다.
- `src/core/report-generator.ts`
  - analyzer 타입을 `AnalysisEngine` 기반으로 변경했다.
- `src/integrations/analysis-factory.ts`
  - `ANALYSIS_AI_PROVIDER` 또는 `ANALYSIS_PROVIDER` 값을 읽어 Claude/OpenAI 분석기를 선택하도록 추가했다.
  - 기본값을 `openai`로 변경했다.
- `src/integrations/openai.ts`
  - OpenAI 기반 분석기 구현을 추가했다.
  - 실환경 응답에서 누락되거나 래핑되는 필드(`topKeywords`, `keywords`)를 fallback으로 보강하도록 수정했다.
- `src/integrations/index.ts`
  - 새 분석기/팩토리 export를 추가했다.
- `package.json`, `package-lock.json`
  - `openai` SDK 의존성을 추가했다.

### 3. 시크릿 요구사항과 기본값 정렬

- `src/cli/security.ts`
  - `workflow onMeetingSync` 실행 시 `NOTION_TOKEN`과 `CLAUDE_API_KEY|ANTHROPIC_API_KEY|OPENAI_API_KEY` 중 하나를 요구하도록 변경했다.
- `src/cli/security.test.ts`
  - 위 보안 요구사항을 검증하는 테스트를 추가했다.
- `src/security/secret-manager.ts`
  - 기본 필수 키를 `OPENAI_API_KEY` 기준으로 조정했다.
- `src/security/security.test.ts`
  - 기본 시크릿 검증 테스트를 OpenAI 기준으로 맞췄다.

### 4. 문서 및 운영 기본값 정리

- `.env.example`
  - `ANALYSIS_AI_PROVIDER="openai"`를 추가해 기본 운영값을 명시했다.
- `프로그램 시작방법.md`
  - 주요 환경 변수 표를 OpenAI 기본 운영 기준으로 정리했다.
  - 기본 운영값이 `ANALYSIS_AI_PROVIDER=openai`라는 설명을 추가했다.
- `프로젝트 명령어 정리.md`
  - `.env` 섹션에 `ANALYSIS_AI_PROVIDER`, `OPENAI_API_KEY` 항목을 추가했다.
  - Claude 전환 시 필요한 설정도 함께 정리했다.

### 실환경 smoke test

- Claude 경로
  - `meeting:synced` 실행 자체는 정상 진입했다.
  - `report-update` 단계에서 Anthropic API 크레딧 부족으로 실패했다.
  - 실패 메시지: `Your credit balance is too low to access the Anthropic API.`
- OpenAI 경로
  - 초기에는 실응답 포맷 차이로 실패했다.
  - `openai.ts` fallback/보정 로직 수정 후 재실행에 성공했다.
  - 실제 생성 결과: `vault/analysis/2026-19_weekly_report.md`

## 현재 운영 기준

- 기본 분석 provider: `openai`

  - `CLAUDE_API_KEY` 또는 `ANTHROPIC_API_KEY` 필요

## 구현 상세

### 1. 타입 정의 (`src/types/linkedin.ts`)

```typescript
type LinkedInTone = 'professional' | 'casual' | 'thought-leader';
type LinkedInPostTemplate = 'lesson' | 'project-update' | 'weekly-story';

interface MissionContent {
  title: string;
  body: string;
  author: string;
  date: Date;
  weekNumber?: number;
  keywords?: string[];
}

interface LinkedInPost {
  headline: string;
  body: string;
  hashtags: string[];
  callToAction?: string;
  suggestedMedia?: string[];
}

interface FormattedPost {
  content: string;
  charCount: number;
  isWithinLimit: boolean;  // LinkedIn 3000자 제한
  hashtags: string[];
  fileName: string;        // {날짜}_{제목}_{작성자}.md
}

const LINKEDIN_CHAR_LIMIT = 3000;
```

### 2. LinkedInContentGenerator 클래스 (`src/integrations/linkedin.ts`)

#### 주요 메서드

| 메서드 | 설명 |
|--------|------|
| `generateDraft(mission)` | Mission 문서 → LLM으로 LinkedIn 게시물 초안 생성 |
| `applyTone(draft, tone)` | professional / casual / thought-leader 톤 변환 |
| `addHashtags(content, keywords)` | 키워드에서 #해시태그 자동 추가 |
| `formatForPlatform(post, mission)` | 3000자 제한 검사 + 파일명 생성 |
| `buildHashtags(keywords)` _(static)_ | 키워드 배열 → #해시태그 배열 변환 |

#### 톤별 프롬프트 전략

| 톤 | 설명 |
|----|------|
| `professional` | 전문적이고 격식 있는 어조. 데이터와 인사이트 중심. |
| `casual` | 친근하고 편안한 어조. 대화하듯 자연스럽게. |
| `thought-leader` | 업계 리더의 관점. 통찰력 있는 메시지와 미래 지향적 시각. |

#### 파일명 규칙

```
{날짜}_{제목(최대 30자)}_{작성자}.md
예) 2026-05-01_React_Hooks_심화_학습_alice.md
```

#### 해시태그 처리 규칙 (`buildHashtags`)
- 공백 포함 키워드 → CamelCase 변환 (`next js` → `#NextJs`)
- 중복 자동 제거 (Set 기반)
- 최대 10개 제한

#### 설계 포인트

- `LLMClient` 인터페이스로 Anthropic SDK 의존성 주입 (테스트 가능성 확보)
- Exponential Backoff 재시도 로직 (최대 3회)
- `generateDraft` 출력 파싱: `### 헤드라인` / `### 본문` / `### CTA` 섹션 분리

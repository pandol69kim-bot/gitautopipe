# 화면설계서

작성일: 2026-05-01  
프로젝트: 셀피시 클럽 AI 에이전트 협업 시스템  
버전: v1.0

> 본 시스템은 CLI(Command Line Interface) 기반으로, 별도의 GUI 화면 없이 터미널 출력으로 사용자와 상호작용한다.

---

## 1. CLI 화면 구성 개요

```
[실행 진입점]
  ├── npm start              → 기본 시작 메시지 출력
  └── node dist/cli/index.js → CLI 명령 진입점
       ├── scan
       ├── sync
       ├── analyze
       ├── deploy
       ├── workflow
       ├── status
       └── interactive (대화형 선택 메뉴)
```

---

## 3. 출력 포맷 옵션

| 포맷 | 설명 | 사용 예 |
|------|------|---------|
| `table` | 기본값, 표 형태로 시각화 | 사람이 읽기 편한 콘솔 출력 |
| `json` | JSON 직렬화 출력 | 스크립트/자동화 파이프라인 연동 |
| `minimal` | 핵심 결과만 간략 출력 | CI/CD 로그 |

---

## 4. 로그 레벨별 출력

| 레벨 | 출력 내용 |
|------|-----------|
| `debug` | 내부 함수 호출, 변수 값, API 요청/응답 상세 |
| `info` | 일반 작업 진행 상황 (기본값) |
| `warn` | 비정상이지만 계속 진행 가능한 상황 |
| `error` | 실행 중단이 필요한 오류 |

## 1. 프로젝트 배경 및 목적

셀피시 클럽 운영에서 발생하는 반복적인 콘텐츠 생성, GitHub 동기화, 회의록 정리, LinkedIn 포스팅 작업을 AI 에이전트로 자동화하여 운영 효율을 극대화한다.

## 2. 프로젝트 범위

| 구분 | 포함 | 제외 |
|------|------|------|
| 플랫폼 | Node.js CLI, 자동화 워크플로우 | 웹 프론트엔드 UI |
| 연동 | Claude, GitHub, Notion, LinkedIn, Vercel | Slack, Discord |
| 데이터 | Obsidian/Markdown 볼트 | 외부 DB |

## 4. 기술 방향성

- **언어**: TypeScript (CommonJS)
- **아키텍처**: CLI → 보안 래퍼 → 워크플로우 오케스트레이터 → 도메인 모듈
- **이벤트 기반**: 워크플로우를 이벤트/cron으로 트리거
- **보안**: rate limit, secret manager, audit log, access control

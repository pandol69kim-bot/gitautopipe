## 1. 기능 요구사항 (Functional Requirements)

### 1.1 CLI 명령 시스템

| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| FR-01 | 사용자는 CLI로 `scan`, `sync`, `analyze`, `deploy`, `workflow`, `status`, `interactive` 명령을 실행할 수 있어야 한다 | P0 |
| FR-02 | 출력 포맷은 `table`, `json`, `minimal` 중 선택 가능해야 한다 | P1 |
| FR-03 | 대화형 모드(interactive)에서 명령을 선택하여 실행할 수 있어야 한다 | P1 |

| FR-11 | 파일의 frontmatter(gray-matter)를 파싱하여 메타데이터를 추출해야 한다 | P0 |

## 2. 비기능 요구사항 (Non-Functional Requirements)

| ID | 구분 | 요구사항 |
|----|------|----------|
| NFR-01 | 성능 | CLI 명령 응답 시간 5초 이내 (외부 API 제외) |
| NFR-02 | 보안 | .env 파일은 .gitignore에 포함, 시크릿은 환경변수로만 관리 |
| NFR-03 | 유지보수성 | TypeScript strict 모드, zod 스키마 검증 |
| NFR-04 | 이식성 | Node.js 18 이상에서 동작 |
| NFR-05 | 로깅 | 로그 레벨(debug/info/warn/error) 선택 가능 |
| NFR-06 | 테스트 | 핵심 모듈 단위 테스트 커버리지 확보 (Vitest) |

## 3. 제약사항

- Node.js 런타임 전용 (브라우저 환경 미지원)
- Claude API, GitHub API, Notion API, LinkedIn API 키 필수
- Vercel 배포는 Vercel CLI/API 토큰 필요
- 멀티 사용자 동시 실행 미지원 (단일 사용자 CLI)

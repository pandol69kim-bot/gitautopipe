---

1. onGitHubSync

  • 이름: GitHub 동기화
  • 트리거: github:sync 이벤트
  • 에러 처리: stop

    • 스텝

  • github-pull
  • 이름: 원격 최신화 (pull)
  • 설명: 원격 저장소에서 최신 변경을 pull
  • github-status
  • 이름: 변경 파일 확인
  • 설명: 수정/생성/삭제 파일 목록과 총 변경 건수 확인
  • github-commit-push
  • 이름: 커밋 및 푸시
  • 설명: 변경 파일이 있으면 커밋 메시지를 생성해 push, 없으면 커밋 생략

    • ---

    2. onNotionSync

  • 이름: Notion 동기화
  • 트리거: notion:sync 이벤트
  • 에러 처리: stop

    • 스텝

  • notion-sync-bidirectional
  • 이름: Notion-Obsidian 양방향 동기화
  • 설명: Notion DB와 Obsidian meetings 폴더를 양방향 동기화하고 summary를 payload에 반영

    • ---

    3. onMissionUpdate

  • 이름: Mission 업데이트 처리
  • 트리거: mission:updated 이벤트
  • 에러 처리: continue

    • 스텝

  • mission-collect
  • 이름: Mission 파일 수집
  • 설명: 최신 Mission 문서를 읽어 제목, 작성자, 주차, 본문을 payload에 적재
  • openai-analyze
  • 이름: OpenAI 분석 실행
  • 설명: Mission 문서를 OpenAI로 분석해 vault/analysis에 분석 보고서를 생성
  • linkedin-draft
  • 이름: LinkedIn 초안 생성
  • 설명: Mission 내용과 분석 결과를 바탕으로 OpenAI 기반 LinkedIn 초안 파일을 vault/linkedin에 생성

    • ---

    4. onMeetingSync

  • 이름: Notion 미팅 동기화
  • 트리거: meeting:synced 이벤트
  • 에러 처리: retry
  • 재시도 설정: 최대 2회, 지연 1000ms

    • 스텝

  • notion-fetch
  • 이름: Notion 미팅 데이터 조회
  • obsidian-sync
  • 이름: Obsidian 동기화
  • report-update
  • 이름: Analysis 보고서 업데이트

    • ---

    5. onSkillUpdate

  • 이름: Skill/Insight 게시물 배포
  • 트리거: skill:updated 이벤트
  • 에러 처리: stop

    • 스텝

  • site-build
  • 이름: 정적 사이트 빌드
  • vercel-deploy
  • 이름: Vercel 배포
  • deploy-notify
  • 이름: 배포 알림 전송

    • ---

    6. weeklyDigest

  • 이름: 주간 다이제스트 생성
  • 트리거: cron 0 9 1
  • 에러 처리: continue
  • 기본 스케줄 자동 등록: 0 9 1

    • 스텝

  • vault-scan
  • 이름: 볼트 주간 데이터 수집
  • 설명: meetings 폴더를 스캔해 대상 주차 문서를 수집하고 payload에 저장
  • weekly-report
  • 이름: 주간 보고서 생성
  • 설명: 수집한 주간 데이터로 Analysis 주간 보고서를 생성하고 vault/analysis에 저장
  • github-commit
  • 이름: GitHub 커밋
  • 설명: GitHub 환경 변수가 준비되어 있으면 생성된 보고서를 커밋/푸시하고, 없으면 skip
  • digest-notify
  • 이름: 다이제스트 알림 전송
  • 설명: WEEKLY_DIGEST_WEBHOOK_URL이 설정되어 있으면 Slack/Discord 호환 webhook으로 실제 알림을 전송하고, 없으면 skip

    • 실행 흐름

  • node ./dist/cli/index.js workflow weeklyDigest 실행
  • CLI 보안 검증에서 workflow 실행 권한과 AI 시크릿 그룹 확인
  • runWorkflow()가 orchestrator.executeWorkflow('weeklyDigest') 호출
  • vault-scan이 주간 meetings 데이터를 payload에 적재
  • weekly-report가 Analysis 주간 보고서 파일 생성
  • github-commit이 GitHub 설정 존재 시 커밋/푸시, 없으면 skip
  • digest-notify가 최종 요약 정보를 반환
  • CLI가 executionId, status, stepResults, totalDurationMs를 출력
